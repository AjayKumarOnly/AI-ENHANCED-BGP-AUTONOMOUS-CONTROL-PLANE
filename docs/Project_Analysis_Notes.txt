2. SYSTEM ARCHITECTURE (confirmed from run_autonomous_controller.py)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

AutonomousBGPController runs 5 concurrent asyncio coroutines:

  1. _telemetry_loop   — polls FRR at 1s interval, builds snapshots
                         → feeds asyncio.Queue (maxsize=8) snapshot_q
  2. _inference_loop   — consumes snapshots, extracts 10-feature vectors,
                         runs ML + hybrid trust → feeds decision_q
  3. _policy_actor     — single consumer; batches decisions per snapshot,
                         enforces anti-thrashing, performs atomic FRR commit
  4. _heartbeat_loop   — peer reachability check every 10s (no extra Docker calls)
  5. _metrics_loop     — CPU/RAM collection every 5s

Additional confirmed properties:
  - Startup state reconciliation: SQLite active_policies vs live FRR RIB
  - If discrepancy found: re-applies stored policies or clears stale overrides
  - Atomic all-or-nothing policy apply: full rollback on any per-prefix failure
  - SQLite state_store: persists active policies across restarts
  - ShadowValidator params: shadow_duration_sec=4.0, required_consecutive_ticks=2,
                            min_dwell_sec=10.0
  - RollbackManager params: required_normal_ticks=3
  - Class labels: 0=Normal, 1=Suspicious, 2=Route Leak Candidate,
                  3=Prefix Hijack Candidate

4. FEATURE EXTRACTION (confirmed from src/ai/feature_extractor.py)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Index  Name                     Computation
  0    as_path_len              len(as_path.split())
  1    as_path_edit_distance    Levenshtein DP vs per-prefix baseline path
  2    origin_as_change         1.0 if origin AS ≠ PREFIX_BASELINES, else 0.0
  3    prefix_mask_len          /N parsed from prefix CIDR notation
  4    announcements_per_minute (state transitions in last 60s / elapsed_sec) * 60
  5    flap_count_5min          pairwise path/origin changes in last 300s sliding window
  6    loc_pref_current         BGP LocalPref from RIB (default 100)
  7    route_age_seconds        now − last_update_epoch (true measured, not synthetic)
  8    valley_free_violation    1 if AS path violates Gao-Rexford (RFC 9234 DFA)
  9    neighbor_diversity       active_announcing_peers / total_known_peers (clipped [0,1])

Key implementation details:
  - Levenshtein computed as numpy DP (O(mn) exact algorithm)
  - valley_free check: DFA over AS_RELATIONSHIPS dict (states: UPWARD/PEER/DOWNWARD)
    AS loops (duplicate ASN in path) always flagged as violation
  - AS_RELATIONSHIPS encodes real-world AS pairs including Google/Rostelecom,
    Cloudflare/Verizon/Allegheny, Pakistan Telecom/YouTube for historical incidents
  - route_age_seconds uses last_update_epoch if available; falls back to first-seen
    timestamp from sliding_window_events

Trust output: weighted sum ∈ [0.0, 1.0]

Trust-to-policy mapping (policy_engine.py map_trust_to_policy):
  class_id=3 OR trust < 0.25   → LP 0  + community no-export  [Quarantine]
  class_id=2 OR trust < 0.55   → LP 50                        [Hard Deprioritise]
  class_id=1 OR trust < 0.80   → LP 80                        [Soft Deprioritise]
  class_id=0 AND trust ≥ 0.85  → LP 100                       [Normal / Rollback]
  Hysteresis: when existing policy is non-100, recovery requires trust ≥ 0.85 AND class 0

11. CONFIRMED LIMITATIONS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

(a) PARTIAL RIB VISIBILITY
    Controller only inspects routes installed as best-path by the vantage AS.
    Non-selected paths and withdrawn routes are not examined. A route leak that
    propagates via an upstream AS but is never installed at vantage will be missed.

(b) SMALL TRAINING DATASET
    435 empirical samples; macro F1=0.4542 for RF indicates poor recall on rare
    anomaly classes (Suspicious, Route Leak) in the 87-sample holdout.
    Not sufficient for production-grade generalisation.

(c) DRY-RUN BENCHMARK
    live_benchmark_results.json is explicitly a dry-run; presented MTTD values
    for S2–S4 are estimates, not live measurements.

(d) HEURISTIC DETECTOR FALSE NEGATIVES
    A1 heuristic detector fails to detect S1 (prefix hijack) — confirmed by CSV.
    Static thresholds miss hijacks without anomalous flap rate.

(e) RF/LR PARITY
    Both models achieve similar weighted F1 (~0.81). Neither is clearly dominant;
    the presentation does not claim RF is superior to LR.

(f) TESTBED SCOPE
    10-AS containerised testbed on Windows 11 + Docker.
    No evaluation on Linux-native BGP routers or real Internet peering sessions.

(g) 4s SHADOW DWELL ADDS LATENCY
    MTTD 4.12s vs RPKI <0.10s is an expected architectural tradeoff. The shadow
    dwell prevents over-reaction to transient events but increases detection time.
